# PP-OCRv6 Tiny Chinese

This package contains the ONNX detector, optional direction classifier,
recognizer, and UTF-8 recognition dictionary used by lw.PPOCR.OpenCVDNN.

The relative paths and input shapes are declared in `model.json`. Keep the
manifest and all referenced files together when deploying the model.

Model artifacts originate from PaddleOCR and are distributed under the
Apache-2.0 terms included in `licenses/PaddleOCR-models-APACHE-2.0.txt`.
