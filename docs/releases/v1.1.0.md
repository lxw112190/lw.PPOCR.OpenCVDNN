# v1.1.0 release / 正式版

`v1.1.0` adds PDF OCR and browser cross-origin configuration while preserving
the C ABI v1, HTTP API v1, and machine-readable v1 schemas.

`v1.1.0` 在保持 C ABI v1、HTTP API v1 以及机器可读 v1 Schema 不变的前提下，
新增 PDF OCR 与浏览器跨域配置能力。

## Highlights / 主要更新

- PDF OCR accepts `application/pdf` uploads through `/api/pdf/ocr`.
- Pages with a usable text layer use extracted text; scanned pages can be
  rendered and sent through OCR, with `auto`, `text`, `ocr`, and `hybrid` modes.
- CORS can be configured in `http-service.json` with `enabled` and an exact
  `allowed_origins` list. Environment variables remain optional deployment-time
  overrides.
- Startup diagnostics print the effective CORS origin list, and duplicate
  origins are rejected by both the configuration Schema and native validation.
- Windows packages bundle the required PDFium runtime and include the PDF
  fixture, API documentation, schemas, examples, licenses, and SHA-256 files.

- PDF OCR 通过 `/api/pdf/ocr` 接收 `application/pdf` 上传。
- 有可用文字层的页面优先提取文字；扫描页可渲染后进入 OCR，并支持 `auto`、
  `text`、`ocr` 和 `hybrid` 模式。
- CORS 可在 `http-service.json` 中通过 `enabled` 与精确的 `allowed_origins`
  配置；环境变量仍作为可选的部署时覆盖项。
- 启动诊断输出实际 CORS origin 列表，Schema 与原生配置校验都会拒绝重复 origin。
- Windows 包包含 PDFium 运行库、PDF 测试文件、API 文档、Schema、示例、许可证和
  SHA-256 校验文件。

## Upgrade / 升级

Extract the complete `v1.1.0` package into a new directory. Stop the old
service, migrate deliberate settings from `http-service.json`, and run
`/health` plus a PDF OCR request before removing the previous package.

请将完整 `v1.1.0` 包解压到新目录，停止旧服务后从 `http-service.json` 迁移明确需要的
配置，并执行 `/health` 和 PDF OCR 请求验证，确认无误后再移除旧包。
