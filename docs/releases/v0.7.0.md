# v0.7.0 development summary / 开发摘要

This cumulative development release completes the v0.5.0-v0.7.0 milestones.

本次累积开发版本完成 v0.5.0～v0.7.0 三个里程碑。

## v0.5.0 quality gate

- Expanded deterministic OCR fixtures and golden regression cases.
- Added binary, JSON/Base64, cropped recognition, orientation, blank-image,
  batch-order, score, coordinate, and image-size assertions.
- Added malformed input, authentication, size-limit, recovery, ASan, and UBSan
  coverage.

## v0.6.0 contract freeze

- Froze HTTP API v1 as OpenAPI, configuration Schema v1, and access-log Schema
  v1 with SHA-256 contract locks.
- Added the `X-LW-PPOCR-API-Version` response header and stable JSON
  `error_code` values.
- Rejects unknown configuration fields and unsupported schema versions.
- Adds native startup rejection tests for invalid configuration documents.

## v0.7.0 supply chain

- Added the vendored dependency/model lock and deterministic CycloneDX 1.6
  SBOM.
- Added CodeQL, pull-request dependency review, Dependabot, security policy,
  compatibility matrix, and dependency/SBOM verification.
- Release packages include schemas, test fixtures, SBOM, dependency lock, and
  the related operating documentation.
